# Screenshot Evidence

Screenshots must be captured from the running application at `http://localhost:5173/lab/experiment-2/events` and stored in this folder. The required evidence set is:

| File | Viewport / state | Demonstrates |
|---|---|---|
| `screenshots/desktop-1440.png` | 1440 × 900, initial page | Hero and three-column grid |
| `screenshots/tablet-768.png` | 768 × 1024, initial page | Two-column grid |
| `screenshots/mobile-375.png` | 375 × 812, initial page | Stacked cards, mobile navigation, full-width buttons |
| `screenshots/registration-success.png` | Any required viewport, after Register click | Registered success state |

Capture date and browser state should be recorded here after the screenshots are taken. No screenshot is considered evidence until it is created from the real running app.

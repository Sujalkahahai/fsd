## Aim
To develop an interactive Event Page using React Hooks and State Management, demonstrating `useState`, `useEffect`, and `useContext`.

## Implemented features
- Search by title, description, or location.
- Category filtering with combined search and empty-state reset.
- Shared registration state through React Context.
- Registration summary with remove action.
- Browser-local persistence using `localStorage` and `useEffect`.
- Responsive one-, two-, and three-column layout.
